# Railway Private Panel

نسخه 1.1.0: محدودیت همزمان اصلاح شد و اکنون بر اساس دستگاه/IP است، پاسخ VLESS سریع‌تر ارسال می‌شود، گزارش اتصال اضافه شده و رابط مدیریت کاربران بازطراحی شده است.

پنل خصوصی و سبک برای ساخت کاربران VLESS + WebSocket + TLS روی Railway.

## هدف

- ساده و مخصوص استفاده خصوصی
- پنل انسانی با رمز مدیریت
- API جداگانه برای ربات با Bearer Token
- SQLite پایدار روی Railway Volume
- Subscription سازگار با v2rayNG
- دامنه رایگان Railway و دامنه شخصی اختیاری
- بدون Cloudflare، WARP، Scanner، Open Proxy یا Proxy-IP عمومی

## شروع

فایل `00-از-اینجا-شروع-کن.txt` را از ابتدا تا انتها بخوانید.

## مسیرها

- `/login` ورود مدیر
- `/dashboard` مدیریت کاربران
- `/api/v1/users` API ربات
- `/sub/{token}` لینک اشتراک کاربر
- `/connect/{token}` اتصال WebSocket اختصاصی
- `/health` بررسی سلامت

## محدودیت‌های عمدی

- فقط VLESS روی WebSocket/TLS و TCP پشتیبانی می‌شود.
- UDP و پورت‌های ایمیل مسدود هستند.
- برای کاهش Abuse هیچ HTTP Open Proxy وجود ندارد.
- این پروژه تضمین ضدتعلیق یا عبور قطعی از محدودیت شبکه نمی‌دهد؛ قوانین میزبان باید رعایت شود.
