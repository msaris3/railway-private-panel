# Railway Private Panel

نسخه 1.2.0: علاوه بر اصلاح محدودیت دستگاه و رابط جدید، مسیر انتقال برای مصرف بالا بهینه شده؛ بررسی دیتابیس هر 3 ثانیه و ثبت مصرف به‌صورت دسته‌های 1 مگابایتی انجام می‌شود.

پنل خصوصی و سبک برای ساخت کاربران VLESS + WebSocket + TLS روی Railway.

## هدف

- ساده و مخصوص استفاده خصوصی
- پنل انسانی با رمز مدیریت
- API جداگانه برای ربات با Bearer Token
- SQLite پایدار روی Railway Volume
- Subscription سازگار با v2rayNG
- دامنه رایگان Railway و دامنه شخصی اختیاری
- بدون Cloudflare، WARP، Scanner، Open Proxy یا Proxy-IP عمومی

## شروع

فایل `00-از-اینجا-شروع-کن.txt` را از ابتدا تا انتها بخوانید.

## مسیرها

- `/login` ورود مدیر
- `/dashboard` مدیریت کاربران
- `/api/v1/users` API ربات
- `/sub/{token}` لینک اشتراک کاربر
- `/connect/{token}` اتصال WebSocket اختصاصی
- `/health` بررسی سلامت

## محدودیت‌های عمدی

- فقط VLESS روی WebSocket/TLS و TCP پشتیبانی می‌شود.
- UDP و پورت‌های ایمیل مسدود هستند.
- برای کاهش Abuse هیچ HTTP Open Proxy وجود ندارد.
- این پروژه تضمین ضدتعلیق یا عبور قطعی از محدودیت شبکه نمی‌دهد؛ قوانین میزبان باید رعایت شود.

## نسخه‌ی ۱.۴.۰

### وب‌پس مخفی (`WEB_PATH`)

اگر متغیر `WEB_PATH` مقدار داشته باشد، کل پنل زیر همان مسیر می‌رود:

```
https://<دامنه>/<WEB_PATH>/login
https://<دامنه>/<WEB_PATH>/dashboard
https://<دامنه>/<WEB_PATH>/api/v1/...
```

ریشه‌ی دامنه و هر مسیر ناشناس دیگری یک صفحه‌ی پوششی بی‌ربط با هدر `noindex` می‌گیرد.

مسیرهایی که عمداً روی ریشه می‌مانند: `/health` (چک سلامت رِیل‌وی)، `/connect/<توکن>` (تونل) و `/s/<توکن>` (لینک اشتراک).

مقدار `WEB_PATH` پاکسازی می‌شود: فقط `A-Z a-z 0-9 _ -` و حداکثر ۴۸ کاراکتر. خالی بگذاری یعنی پنل روی ریشه (توصیه نمی‌شود).

### لینک اشتراک

| مسیر | خروجی |
| --- | --- |
| `/s/<توکن>` | مرورگر → صفحه‌ی HTML؛ برنامه‌ی VPN → base64 |
| `/s/<توکن>/raw` | همیشه base64 |
| `/sub/<توکن>` | مسیر قدیمی، همیشه base64 |

هدرهای `subscription-userinfo`، `profile-title`، `profile-update-interval` و `profile-web-page-url` فرستاده می‌شوند.

صفحه‌ی اشتراک تک‌فایل و بدون CDN است: حجم دقیق، دستگاه متصل، انقضای شمسی، کپی تک‌تک کانفیگ‌ها، دکمه‌ی مستقیم Hiddify / V2Box / v2rayNG / Streisand / Shadowrocket / Clash / sing-box و راهنمای نصب.
