راهنمای خیلی ساده نصب Railway Private Panel
==========================================

این پروژه برای پنل خصوصی شما ساخته شده است.
کلودفلر لازم نیست.
پنل مدیریت با رمز وارد می‌شود و ربات با BOT_API_KEY کار می‌کند.

قبل از شروع چه چیزهایی لازم است؟
--------------------------------
1) یک حساب GitHub
2) یک حساب Railway
3) همین پوشه پروژه
4) حدود 10 دقیقه زمان

بخش اول: گذاشتن فایل‌ها در GitHub
--------------------------------
1) وارد سایت https://github.com شوید.
2) بالای صفحه روی علامت + بزنید.
3) New repository را بزنید.
4) در Repository name بنویسید: railway-private-panel
5) گزینه Private را انتخاب کنید.
6) روی Create repository بزنید.
7) گزینه uploading an existing file را بزنید.
8) همه فایل‌های داخل این پوشه را بکشید و داخل صفحه GitHub رها کنید.
9) پایین صفحه روی Commit changes بزنید.

بخش دوم: ساخت سه رمز لازم
------------------------
سه مقدار متفاوت بسازید. هیچ‌کدام را برای دیگران نفرستید.

ADMIN_PASSWORD
رمزی است که خودتان با آن وارد صفحه مدیریت می‌شوید.
حداقل 12 کاراکتر باشد.

BOT_API_KEY
کلیدی است که فقط به ربات مدیریت می‌دهید.
حداقل 24 کاراکتر باشد.

SESSION_SECRET
کلید داخلی پنل است.
حداقل 32 کاراکتر باشد.

برای ساخت مقدار تصادفی می‌توانید سه بار وارد این سایت شوید:
https://www.uuidgenerator.net/
هر بار مقدار جدیدی کپی کنید. برای SESSION_SECRET دو UUID را پشت سر هم قرار دهید.

بخش سوم: ساخت پروژه در Railway
------------------------------
1) وارد https://railway.app شوید.
2) روی New Project بزنید.
3) Deploy from GitHub Repo را انتخاب کنید.
4) مخزن railway-private-panel را انتخاب کنید.
5) صبر کنید تا Railway پروژه را Build کند.

بخش چهارم: اضافه‌کردن متغیرها
----------------------------
1) داخل Railway روی سرویس ساخته‌شده بزنید.
2) تب Variables را باز کنید.
3) متغیرهای زیر را یکی‌یکی اضافه کنید:

ADMIN_PASSWORD = رمز مدیریت خودتان
BOT_API_KEY = کلید مخصوص ربات
SESSION_SECRET = کلید طولانی داخلی
DATA_DIR = /data

4) بعد از ذخیره، Railway خودکار دوباره Deploy می‌کند.
5) اگر Deploy قرمز شد، بخش Troubleshooting همین فایل را بخوانید.

بخش پنجم: ساخت Volume تا کاربران پاک نشوند
------------------------------------------
این مرحله خیلی مهم است.
1) داخل پروژه Railway روی New بزنید.
2) Volume را انتخاب کنید.
3) Volume را به همین سرویس پنل وصل کنید.
4) Mount Path را دقیقاً بنویسید: /data
5) سرویس را Redeploy کنید.

اگر Volume نگذارید، بعد از تعویض کانتینر ممکن است کاربران پاک شوند.

بخش ششم: ساخت دامنه رایگان Railway
-----------------------------------
1) سرویس را باز کنید.
2) Settings را بزنید.
3) قسمت Networking را پیدا کنید.
4) روی Generate Domain بزنید.
5) Railway یک آدرس شبیه زیر می‌دهد:
https://my-panel.up.railway.app
6) این آدرس را باز کنید.
7) با ADMIN_PASSWORD وارد شوید.

بخش هفتم: ساخت اولین کاربر
--------------------------
1) وارد Dashboard شوید.
2) نام کاربر را بنویسید.
3) حجم را برحسب GB بنویسید. عدد 0 یعنی نامحدود.
4) تعداد دستگاه را بنویسید. پیشنهاد: 2
5) اگر تاریخ انقضا می‌خواهید انتخاب کنید.
6) روی «ساخت و کپی ساب» بزنید.
7) لینک Subscription خودکار کپی می‌شود.
8) لینک را داخل v2rayNG یا کلاینت سازگار Import from clipboard کنید.

بخش هشتم: اتصال ربات
--------------------
1) فایل docs/BOT-BEHAVIOR-FA.md را به ربات هوش مصنوعی بدهید.
2) آدرس پنل را به ربات بدهید؛ مثال:
https://my-panel.up.railway.app
3) مقدار BOT_API_KEY را به‌صورت Secret در تنظیمات امن ربات ذخیره کنید.
4) BOT_API_KEY را داخل پیام عمومی یا کد منتشر نکنید.
5) ربات از مسیر /api/v1/users کاربر می‌سازد و لینک ساب را تحویل می‌دهد.

بخش نهم: دامنه شخصی اختیاری، بدون Cloudflare
---------------------------------------------
دامنه شخصی اجباری نیست.
1) در Railway وارد Settings > Networking شوید.
2) Add Custom Domain را بزنید.
3) دامنه خودتان مثل vpn.example.com را وارد کنید.
4) Railway یک DNS Record به شما نشان می‌دهد.
5) وارد سایت فروشنده دامنه شوید و همان Record را دقیق وارد کنید.
6) منتظر بمانید Railway کنار دامنه وضعیت Active نشان دهد.
7) وارد پنل شوید و در «دامنه‌های اضافه» همان دامنه را اضافه کنید.
8) از این به بعد لینک ساب برای آن دامنه هم کانفیگ می‌سازد.

Cloudflare لازم نیست و در این نسخه استفاده نشده است.

برای ساخت 15 پنل
----------------
برای هر پنل یک Railway Project جدا بسازید.
برای هرکدام ADMIN_PASSWORD، BOT_API_KEY و SESSION_SECRET متفاوت بسازید.
هر پنل Volume جدا روی /data داشته باشد.
هیچ کلیدی را میان 15 پنل تکرار نکنید.

نکات مهم سرعت و پایداری
-----------------------
1) تعداد Worker روی 1 نگه داشته شده تا دیتابیس و آمار صحیح بماند.
2) برای هر کاربر max_connections را 2 یا 3 بگذارید.
3) Open Proxy، Scanner، WARP و Cloudflare Worker عمداً حذف شده‌اند.
4) این پروژه فقط TCP روی VLESS+WebSocket را پشتیبانی می‌کند.
5) UDP، Torrent و پورت‌های ایمیل مسدود هستند تا احتمال Abuse و Suspend کمتر شود.
6) هیچ سرویس رایگانی تضمین ضدتعلیق یا ضد‌فیلتر نمی‌دهد. قوانین Railway را رعایت کنید.

Troubleshooting
===============

مشکل: Deploy قرمز است
راه‌حل:
- Variables را باز کنید.
- ADMIN_PASSWORD حداقل 12 کاراکتر باشد.
- BOT_API_KEY حداقل 24 کاراکتر باشد.
- SESSION_SECRET حداقل 32 کاراکتر باشد.
- Deploy Logs را باز کنید و اولین خط ERROR را بخوانید.

مشکل: صفحه باز نمی‌شود
راه‌حل:
- Settings > Networking را باز کنید.
- Generate Domain را زده باشید.
- Deploy باید سبز باشد.
- مسیر /health را باز کنید. باید {"ok":true} ببینید.

مشکل: وارد پنل نمی‌شود
راه‌حل:
- دقیقاً مقدار ADMIN_PASSWORD را وارد کنید.
- فاصله اول یا آخر رمز را حذف کنید.
- بعد از تغییر Variable یک Redeploy انجام دهید.

مشکل: کانفیگ در v2rayNG وصل نمی‌شود
راه‌حل:
- جدیدترین نسخه v2rayNG با Xray Core را نصب کنید.
- لینک Subscription را Refresh کنید.
- Date/Time گوشی روی Automatic باشد.
- دامنه را در مرورگر باز کنید و مطمئن شوید پنل بالا است.
- در Railway Deploy Logs دنبال خطا بگردید.
- اگر دامنه شخصی تازه ساخته شده، تا Active شدن SSL صبر کنید.

مشکل: کاربران بعد از Redeploy پاک شدند
راه‌حل:
- Volume به سرویس وصل نشده است.
- Volume بسازید و Mount Path را /data بگذارید.
- اطلاعات قبلی بدون Backup قابل بازیابی نیست.

مشکل: ربات خطای 401 می‌دهد
راه‌حل:
- Header باید دقیقاً این باشد:
Authorization: Bearer BOT_API_KEY
- BOT_API_KEY ربات و Railway باید کاملاً یکسان باشند.
- از ADMIN_PASSWORD به‌جای BOT_API_KEY استفاده نکنید.

مشکل: خطای 403 یا اتصال سریع قطع می‌شود
راه‌حل:
- کاربر خاموش، منقضی یا پرحجم نشده باشد.
- تعداد دستگاه هم‌زمان از max_connections بیشتر نباشد.
- برای تست، کاربر جدید با حجم 1 GB و اتصال 2 بسازید.

پایان راهنما
============
اول همیشه /health، سپس Login، سپس ساخت یک کاربر آزمایشی را بررسی کنید.
